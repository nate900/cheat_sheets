Docker Cheat Sheet

Basic workflow: build or pull an image → run a container → inspect it → stop or remove it.

Images

docker pull nginx                         # Download an image
docker images                             # List local images
docker build -t my-app:latest .           # Build from Dockerfile in current directory
docker rmi my-app:latest                  # Remove an image
docker push username/my-app:latest        # Upload an image

Containers

docker run --name web -d -p 8080:80 nginx # Run in background; host port 8080 → container port 80
docker ps                                 # List running containers
docker ps -a                              # List all containers, including stopped
docker stop web                           # Stop a container
docker start web                          # Start a stopped container
docker restart web                        # Restart a container
docker rm web                             # Remove a stopped container
docker rm -f web                          # Force-remove a container

Common docker run flags:

  • -d — run in the background
  • -it — interactive terminal
  • --name NAME — assign a name
  • -p HOST:CONTAINER — publish a port
  • -v SOURCE:DEST — mount a volume or host directory
  • --rm — remove the container automatically when it exits

Debugging and inspection

docker logs web                           # Show logs
docker logs -f web                        # Follow logs live
docker exec -it web sh                    # Open a shell in a running container
docker inspect web                        # Show detailed configuration
docker stats                              # Show live resource usage
docker cp web:/path/file ./file            # Copy a file from container to host

Volumes and networks

docker volume ls                          # List volumes
docker volume create app-data             # Create a named volume
docker run -v app-data:/data my-app       # Mount it at /data

docker network ls                         # List networks
docker network create app-net             # Create a network
docker run --network app-net my-app       # Connect a container to it

Docker Compose

docker compose up -d                      # Build if needed and start services
docker compose ps                         # List Compose services
docker compose logs -f                    # Follow service logs
docker compose exec <service> sh          # Open a shell in a service
docker compose down                       # Stop and remove services/networks

Cleanup

docker system df                          # See Docker disk usage
docker container prune                    # Remove stopped containers
docker image prune                        # Remove unused images
docker system prune                       # Remove unused containers, networks, images, and build cache
Tip: Containers are disposable, so use a volume or bind mount for data you need to keep. Cleanup commands remove unused resources; review what will be deleted before confirming.
