Common Grep Commands

  • grep 'pattern' file.txt - Search for 'pattern' in file.txt
  • grep -i 'pattern' file.txt - Case-insensitive search
  • grep -r 'pattern' /path/to/directory - Recursive search in a directory
  • grep -n 'pattern' file.txt - Show line numbers with matches
  • grep -v 'pattern' file.txt - Invert match (show lines that do not match)
  • grep -E 'pattern1|pattern2' file.txt - Use extended regex for multiple patterns

Locate Files with find and locate

  • find /path -name "filename" # Find by exact name pattern
  • find . -iname "*report*.pdf" # Case-insensitive; partial name
  • find /home -type f -name "*.conf" # Files only
  • find /var -type d -name "cache" # Directories only
  • find . -name "*.log" -mtime -7 # Modified within the last 7 days
  • find . -name "*.log" -size +100M # Larger than 100 MB
