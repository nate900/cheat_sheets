curl Cheat Sheet

Common commands for making HTTP requests, downloading files, and working with APIs.

Basic pattern

curl [options] URL

By default, curl sends the response body to the terminal. Put the URL in quotes if it contains characters your shell might interpret.

Request a page

# Basic GET request
curl "https://example.com"

# Follow redirects
curl -L "https://example.com"

# Show response headers along with the body
curl -i "https://example.com"

# Request headers only
curl -I "https://example.com"

# Verbose connection and request details
curl -v "https://example.com"

Download and save files

# Save response to a chosen filename
curl -o page.html "https://example.com"

# Save using the remote filename
curl -O "https://example.com/archive.zip"

# Follow redirects and save using the remote filename
curl -L -O "https://example.com/archive.zip"

# Resume a download
curl -C - -O "https://example.com/archive.zip"

HTTP methods and request data

# GET with query parameters
curl -G --data-urlencode "q=some words" "https://example.com/search"

# POST form fields (curl sends a POST when using --data)
curl --data "name=Sam&city=Oslo" "https://example.com/submit"

# POST JSON
curl --request POST \
  --header "Content-Type: application/json" \
  --data '{"name":"Sam","active":true}' \
  "https://api.example.com/items"

# PATCH JSON
curl --request PATCH \
  --header "Content-Type: application/json" \
  --data '{"active":false}' \
  "https://api.example.com/items/123"

# DELETE request
curl --request DELETE "https://api.example.com/items/123"

Headers and authentication

# Add a request header
curl --header "Accept: application/json" "https://api.example.com/items"

# Bearer token (replace placeholder; avoid sharing real tokens)
curl --header "Authorization: Bearer YOUR_TOKEN" \
  "https://api.example.com/items"

# Basic authentication (curl prompts for the password)
curl --user "YOUR_USERNAME" "https://api.example.com/private"

# Send cookies
curl --cookie "session=YOUR_COOKIE_VALUE" "https://example.com"

Upload files

# Multipart form upload
curl --form "description=Sample file" \
  --form "file=@./report.pdf" \
  "https://example.com/upload"

# Send a file's contents as the request body
curl --upload-file "./archive.zip" "https://example.com/upload/archive.zip"

Useful options

  • -L, --location — follow redirects.
  • -o FILE — write output to a named file.
  • -O — save using the remote filename.
  • -sS — hide the progress meter but still show errors.
  • -i — include response headers in output.
  • -I — request headers only.
  • -H, --header — add a request header.
  • --connect-timeout SECONDS — set a connection timeout.
  • --max-time SECONDS — limit the total transfer time.
  • --fail-with-body — return an error for HTTP error responses while keeping the response body.
# Quiet output, but show errors; stop after 20 seconds
curl -sS --max-time 20 "https://example.com"

See the HTTP status code

curl -sS -o /dev/null -w "HTTP %{http_code}\n" \
  "https://example.com"

On Windows PowerShell, use NUL instead of /dev/null:

curl.exe -sS -o NUL -w "HTTP %{http_code}\n" "https://example.com"

Quick tips

  • Use --help for a short options overview and --manual for the full manual.
  • For JSON, quote the data carefully; shell quoting differs between operating systems.
  • Avoid putting passwords or tokens directly in commands you may save in shell history.
  • Avoid -k / --insecure for routine use: it disables certificate verification.
  • For troubleshooting, try -v; it prints detailed request and connection information.
