Vim Commands

Modes

  • i — insert before cursor; a — insert after cursor
  • o / O — open a line below / above
  • Esc — return to Normal mode
  • : — enter Command-line mode

Move around (Normal mode)

  • h / j / k / l — left, down, up, right
  • w / b — next / previous word
  • 0 / $ — start / end of line
  • gg / G — first / last line
  • :number — jump to a line, e.g. :25
  • Ctrl-d / Ctrl-u — scroll down / up half a screen

Edit

  • x — delete character
  • dd — delete line; yy — copy line; p — paste after cursor
  • dw — delete word; D — delete to end of line
  • u — undo; Ctrl-r — redo
  • r{char} — replace one character
  • ciw — change the word under the cursor
  • . — repeat the last change

Search and replace

  • /text — search forward; ?text — search backward
  • n / N — next / previous match
  • :%s/old/new/g — replace all occurrences in the file
  • :%s/old/new/gc — replace all, confirming each

Save and quit

  • :w — save
  • :q — quit
  • :wq or ZZ — save and quit
  • :q! — quit without saving
  • :e filename — open a file
